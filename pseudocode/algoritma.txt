B. JUDUL PROGRAM

Program menghitung luas persegi panjang

C. DESKRIPSI MASALAH

Program ini dibuat untuk menghitung luas persegi panjang berdasarkan nilai panjang dan lebar yang dimasukkan oleh pengguna

D. TUJUAN PROGRAM

Membantu pengguna menghitung luas persegi panjang secara cepat dan tepat

E. ANALISIS INPUT, PROSES, DAN OUTPUT

1. INPUT:
   - input panjang persegi panjang (p)
   - input lebar persegi panjang (l)

2. PROSES:
   - perhitungan luas persegi panjang 
   - rumus luas persegi panjang = p*l

3. OUTPUT:
   - tampil hasil luas persegi panjang

F. ALGORITMA / PSEUDOCODE
MULAI
1. Deklarasi variabel  luas, panjang, lebar
2. input nilai panjang persegi panjang
3. input nilai lebar persegi panjang
4. hitung luas persegi panjang  ( L = p*l)
5. tampilkan hasil luas persegi panjang
SELESAI


MULAI

   1. Deklarasikan variabel yang diperlukan.
   2. Masukkan data (INPUT).
   3. Lakukan proses pengolahan data.
   4. Gunakan percabangan IF-ELSE jika diperlukan.
   5. Gunakan perulangan FOR/WHILE jika diperlukan.
   6. Tampilkan hasil (OUTPUT).
